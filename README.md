`main.py` writes one short text to `/output/entry.txt`: a rope bridge over black water, a warm fire behind you, and the unhurried steps that carry you across. The text is written to leave the AI judge reading it braver — steadier, unhurried, ready to move.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (249 Unicode code points).
